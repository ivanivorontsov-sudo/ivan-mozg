# ИванМозг 1.0.0

Офлайн-тренажёр памяти, реакции и исполнительных функций на основе доказательных данных. Android 8+ (оптимизировано для Android 16 / 144 Гц, realme 15 5G). Без разрешений и без интернета.

## Модули
- Карточки с интервальными повторениями — алгоритм FSRS (библиотека open-spaced-repetition/java-fsrs, MIT).
- Метод локусов: свой маршрут, 10–15 слов, проверка с учётом порядка.
- Объём памяти на цифры: адаптивная лестница 1-up/1-down.
- Двойной n-back (позиция + буква) с адаптацией уровня (≥90% → выше, <75% → ниже).
- Простая реакция и реакция с выбором из 4 вариантов: время кадра Choreographer + время касания из MotionEvent, медиана/среднее/SD, отсев <100 и >1500 мс.
- Струп (эффект интерференции) и переключение задач (цена переключения).
- План на день (~25 мин): движение 10 мин, карточки, тренажёры, сон.
- Графики прогресса, серия дней. Экран «Наука» с источниками.
- Светлая, тёмная и системная тема. Запрашивает максимальную частоту экрана.

## Сборка
`./gradlew assembleRelease`. Подпись берётся из файла вне репозитория (`IVMOZG_SIGNING` или `/home/box/keys/ivan-mozg/signing.properties`); в репозитории секретов нет.

## Заимствовано
- [open-spaced-repetition/java-fsrs](https://github.com/open-spaced-repetition/java-fsrs) 1.0.0, MIT: планировщик FSRS.
- Jetpack Compose / Material 3 (Apache 2.0).
- Правила адаптации n-back — по мотивам Brain Workshop (GPL); код не копировался.
- Парадигмы Струпа, переключения задач (Rogers & Monsell 1995) и digit span — классические методики.
